# Phase 07 - Portfolio Generation & Website Hosting

## Overview

In this phase, the extracted resume content is transformed into a professional portfolio website. AWS Lambda uses the structured data generated by Amazon Bedrock to populate HTML templates and create a static website.

The generated website is uploaded to Amazon S3 and delivered through Amazon CloudFront for fast and secure access.

---

## Objectives

- Generate a portfolio website automatically from resume data
- Populate HTML templates with AI-generated content
- Store generated website files in Amazon S3
- Deliver the website using Amazon CloudFront
- Validate the generated portfolio

---

## AWS Services Used

| Service | Purpose |
|---------|---------|
| AWS Lambda | Generates the portfolio website |
| Amazon S3 | Stores generated website files |
| Amazon CloudFront | Delivers the website globally |
| Amazon Bedrock | Provides structured resume data |
| Amazon CloudWatch | Logs and monitors the generation process |

---

## Workflow

1. Lambda receives structured resume data.
2. HTML templates are populated with user information.
3. Portfolio files are generated.
4. Generated files are uploaded to Amazon S3.
5. CloudFront serves the portfolio website.
6. User accesses the generated portfolio.

## Implementation

### Step 1 - Receive Resume Data

The portfolio generation Lambda receives structured JSON generated by Amazon Bedrock.

Example:

```json
{
  "name": "John Doe",
  "title": "Cloud Engineer",
  "summary": "...",
  "skills": [],
  "experience": [],
  "projects": []
}
```

---

### Step 2 - Populate HTML Template

Replace template placeholders with resume data.

Example:

```html
<h1>{{name}}</h1>

<h2>{{title}}</h2>

<p>{{summary}}</p>
```

Generated Output:

```html
<h1>John Doe</h1>

<h2>Cloud Engineer</h2>

<p>Experienced Cloud Engineer...</p>
```

---

### Step 3 - Generate Portfolio Files

Generate the required files.

- index.html
- style.css
- script.js

---

### Step 4 - Upload to Amazon S3

Upload the generated website files to the portfolio bucket.

Example folder structure:

```text
portfolio-bucket/

john-doe/
├── index.html
├── css/
├── js/
└── assets/
```

---

### Step 5 - Deliver with CloudFront

CloudFront serves the generated website, improving performance and reducing latency.

Example:

```
https://xxxxxxxx.cloudfront.net/john-doe/
```

## Challenges

### Dynamic HTML Generation

Generating HTML from structured JSON required mapping multiple sections such as skills, experience, and projects while keeping the template reusable.

### File Organization

Each generated portfolio was stored in its own folder to avoid conflicts between users.

### CloudFront Caching

After updating portfolio files, cache invalidation may be required before changes become visible.

---

## Best Practices

- Keep HTML templates separate from Lambda code.
- Store generated files in dedicated user folders.
- Keep S3 buckets private and use CloudFront for delivery.
- Log portfolio generation steps using CloudWatch.
- Validate AI-generated data before generating HTML.
