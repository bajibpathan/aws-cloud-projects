# ☁️ AWS Services Reference

![AWS](https://img.shields.io/badge/AWS-Services-FF9900?logo=amazonaws&logoColor=white)
![Portfolio](https://img.shields.io/badge/Portfolio-Reference-blueviolet)

This document provides an overview of the AWS services demonstrated throughout this portfolio, their primary purpose, and the current level of hands-on experience gained through production-inspired projects.

The objective is not simply to learn AWS services individually, but to understand **when**, **why**, and **how** they are used together to build secure, scalable, reliable, and well-architected cloud solutions.

---

# 🎯 Purpose

This reference serves as a quick guide to the AWS services covered across the portfolio.

It helps readers understand:

- Which AWS services have been demonstrated
- The role of each service within cloud architectures
- Current learning progress across different AWS domains
- Future areas of exploration
